# Reel Cutter

ブラウザだけで動く、リール/ショート動画向けの編集ツールです。インストール不要で `index.html` を開くだけで使えます。サーバー処理は一切なく、動画・音声の処理はすべて端末内(ブラウザ内のWASM版FFmpeg)で行われます。

## できること

- **カット&結合**: 複数の動画を読み込み、IN/OUTで不要な部分を切り取ってタイムラインに並べ、1本に結合
- **無音の自動カット(ジャンプカット)**: ボタン一つで無音区間を検出し、自動でタイムラインから除去してテンポ良く繋げる
- **カット間のトランジション**: フェード/ディゾルブ/ワイプ/スライド/円形など、カットのつなぎ目に効果を追加
- **自動文字起こし+テロップ**: 音声認識(Whisper, ブラウザ内で実行)でセリフを書き出し、5種類のスタイル×7種類のアニメーション(スライドイン、ポップなど)を組み合わせてテロップを挿入。手動追加・編集も可能
- **画像/動画オーバーレイ**: 指定した時間帯に画像や動画をプレビュー上でドラッグ&リサイズしながら重ねて表示。複数重ねて前面/背面を入れ替え可能(マルチトラック)
- **グラフ・チャート作成**: 棒グラフ/折れ線グラフ/円グラフをアニメーション付きで自動生成し、オーバーレイとして動画に挿入
- **音声**: BGM(ループ対応)、著作権フリーの効果音7種(ブラウザ内で生成)、マイクからのボイスオーバー録音を、動画の音声にミックス
- **色調補正**: クリップごとに明るさ・コントラスト・彩度・色相を自由に調整
- **Undo/Redo・キーボードショートカット**: 編集操作の取り消しと、Space/矢印キーなどでの素早い操作
- **プロジェクトの保存/再開**: ブラウザ内(IndexedDB)にプロジェクトを保存し、後から続きを編集
- **書き出し**: 縦型(9:16)/正方形(1:1)/横型(16:9)、24fps/30fps を選んでMP4として書き出し

## 使い方

1. `index.html` をブラウザ(最新のChrome/Edge/Safariを推奨)で開く
2. 「① 素材」から動画ファイルを追加し、「+ タイムラインに追加」で並べる
3. 各クリップのIN/OUT数値で不要な部分をカット。必要ならトランジションを設定
4. 「③ テロップ」タブで自動文字起こし、またはテロップを手動追加してスタイル・アニメーションを選択
5. 「④ オーバーレイ」タブで画像/動画を追加し、プレビュー上で位置・サイズを調整
6. 「⑤ グラフ作成」タブでデータを入力してグラフ動画を生成し、オーバーレイとして配置
7. 「⑥ 音声」タブでBGM・効果音・ボイスオーバーを追加
8. 「⑦ 色調補正」タブでクリップを選択して色味を調整
9. 「⑧ 書き出し」タブで出力サイズ・フレームレートを選び「書き出す」

作業内容は左上の「プロジェクト」から保存でき、Ctrl+Zで元に戻せます。ショートカット一覧はタイムライン下部に表示されています。

## 技術構成

- 素の HTML/CSS/JavaScript(ビルド不要)
- [`@ffmpeg/ffmpeg`](https://github.com/ffmpegwasm/ffmpeg.wasm)(WASM版FFmpeg): カット・結合・トランジション・オーバーレイ合成・テロップ焼き込み(アニメーション込み)・音声ミックス・色調補正・最終書き出し
- [`@xenova/transformers`](https://github.com/xenova/transformers.js)(Whisper tiny): ブラウザ内音声認識による自動文字起こし
- Web Audio API: 効果音の生成、グラフ動画の音声処理
- Canvas + MediaRecorder: グラフ・チャート動画の生成
- IndexedDB: プロジェクトの保存/読み込み
- すべてCDN経由で動的読み込み。初回利用時にモデル/コアのダウンロードが発生します(数十MB、以降はブラウザキャッシュ)

## 制限事項

- 完全にブラウザ内で処理するため、長尺・高解像度素材は処理に時間がかかったり、メモリ不足になる場合があります。まずは短めの素材でお試しください
- 自動文字起こしはWhisper tinyモデルを使用しており、認識精度は完璧ではありません。書き出し前に文言を確認・修正してください
- オーバーレイ動画自体の音声は書き出しに含まれません(ベース動画+BGM/効果音/ボイスオーバーのみ)
- 効果音はInstagramで実際に流行している音源そのものではなく、著作権フリーでブラウザ内生成した定番効果音(ホイッシュ、ポン、ドラムロールなど)です
- テロップのアニメーションとトランジションは、プレビュー画面には反映されません(書き出した動画でご確認ください)
- Web Speech APIではなくWhisperのWASM実行を採用しているため、Chromeに限らずWASMに対応した主要ブラウザで動作します
